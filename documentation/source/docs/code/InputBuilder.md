# Input File Builder

The interactive input-file builder lets you assemble a CosmoLattice parameter
file directly in your browser. Select a model, fill in the parameters, and copy
or download the generated input file.

!!! tip "Open in a separate tab"
    If the embedded app below feels cramped, you can open it full-screen at
    [cosmolattice-inputgen.streamlit.app](https://cosmolattice-inputgen.streamlit.app).
