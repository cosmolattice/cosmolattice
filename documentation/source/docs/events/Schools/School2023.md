<!-- **2nd $\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$ School** -->

The **2nd $\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$ school** was held online during Sept. 25-29 2023. The school provided a pedagogical introduction to lattice field theory techniques and their adaptation to simulate the dynamics of interacting fields in an expanding background.

The lectures also introduced $\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$ as a public code for lattice simulations of early Universe scenarios. The program covered the use of $\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$ to simulate the non-linear dynamics of scalar and gauge fields in an expanding Universe, together with applications to inflation, preheating, gravitational wave production, non-minimally coupled scalar field dynamics, axion-like field dynamics, and related topics.

<span style="font-size: 30px; font-weight: bold;">Topics</span>

<ul style="line-height: 1.2; margin-top: 0.4em; margin-bottom: 1em; margin-left: 1cm;">
  <li style="margin: 0 0 0.4em 0;">
    <strong>Lattice field theory techniques:</strong> discretisation schemes, lattice gauge techniques, and more.
  </li>
  <li style="margin: 0 0 0.4em 0;">
    <strong>Numerical algorithms for differential equations:</strong> Leapfrog, Verlet, Runge-Kutta, etc.
  </li>
  <li style="margin: 0 0 0.4em 0;">
    <strong>Overview of CosmoLattice:</strong> libraries, modularity, parallelisation, etc.
  </li>
  <li style="margin: 0 0 0.4em 0;">
    <strong>Lattice simulations of interacting fields in an expanding background:</strong>
    <ul style="line-height: 1.2; margin-top: 0.2em; margin-bottom: 0;">
      <li style="margin: 0;">Scalar field dynamics with arbitrary potentials.</li>
      <li style="margin: 0;">U(1) gauge theories with complex charged scalars.</li>
      <li style="margin: 0;">SU(2) gauge theories with doublet charged scalars.</li>
    </ul>
  </li>
  <li style="margin: 0;">
    <strong>Modern applications to early Universe scenarios:</strong>
    <ul style="line-height: 1.2; margin-top: 0.2em; margin-bottom: 0;">
      <li style="margin: 0;">Preheating scenarios and the onset of radiation domination.</li>
      <li style="margin: 0;">Production and evolution of gravitational waves.</li>
      <li style="margin: 0;">Dynamics of derivatively coupled axion-like fields.</li>
      <li style="margin: 0;">Dynamics of non-minimally coupled scalar fields.</li>
      <li style="margin: 0;">Other topics, time permitting.</li>
    </ul>
  </li>
</ul>
