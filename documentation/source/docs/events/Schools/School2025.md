<!-- **3rd School: 2025 (Daejeon)** -->

The **3rd $\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$ school** was held at the Institute for Basic Science (IBS) in Daejeon, South Korea, during Sept. 22-26 2025. The school offered a pedagogical introduction to lattice field theory techniques and their application to simulations of interacting fields in an expanding Universe. Participants were also introduced to <a href="https://cosmolattice.net" target="_blank" rel="noopener noreferrer">$\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$</a>, an open-access code designed for such simulations. The school provided a comprehensive guide to using $\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$ to model the non-linear dynamics of scalar and gauge fields in cosmological contexts.

<span style="font-size: 30px; font-weight: bold;">Topics</span>

<ul style="line-height: 1.2; margin-top: 0.4em; margin-bottom: 1em; margin-left: 1cm;">
  <li style="margin: 0 0 0.4em 0;">
    <strong>Lattice field theory techniques:</strong> discretization schemes, lattice gauge techniques, and more.
  </li>
  <li style="margin: 0 0 0.4em 0;">
    <strong>Numerical algorithms for differential equations:</strong> Leapfrog, Verlet, Runge-Kutta, etc.
  </li>
  <li style="margin: 0 0 0.4em 0;">
    <strong>Overview of CosmoLattice:</strong> libraries, modularity, parallelization, etc.
  </li>
  <li style="margin: 0 0 0.4em 0;">
    <strong>Lattice simulations of interacting fields in an expanding background:</strong>
    <ul style="line-height: 1.2; margin-top: 0.2em; margin-bottom: 0;">
      <li style="margin: 0;">Scalar field dynamics with arbitrary potentials.</li>
      <li style="margin: 0;">U(1) gauge theories coupled to complex charged scalars.</li>
      <li style="margin: 0;">SU(2) gauge theories coupled to doublet charged scalars.</li>
    </ul>
  </li>
  <li style="margin: 0;">
    <strong>Modern applications to early Universe scenarios:</strong>
    <ul style="line-height: 1.2; margin-top: 0.2em; margin-bottom: 0;">
      <li style="margin: 0;">Preheating scenarios and onset of radiation domination.</li>
      <li style="margin: 0;">Production and evolution of gravitational waves.</li>
      <li style="margin: 0;">Dynamics of derivatively coupled axion-like fields.</li>
      <li style="margin: 0;">Dynamics of non-minimally coupled scalar fields.</li>
      <li style="margin: 0;">Fluid dynamics and gravitational waves from turbulence.</li>
      <li style="margin: 0;">Evolution and experimental signatures of topological defects.</li>
    </ul>
  </li>
</ul>
