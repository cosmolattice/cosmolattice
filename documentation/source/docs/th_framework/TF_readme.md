**Theoretical Framework**

In this <!-- **Theoretical Framework**  --> Tab the user can find all the details of the theoretical aspects behind $\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$. Namely,  

-  Section [Monographic Reviews](MonographicReviews.md) presents the theoretical basis for the equations implemented in $\mathcal{C}\mathtt{osmo}\mathcal{L}\mathtt{attice}$. As the theoretical framework - based on **Lattice Cosmology Techniques (LCT)** - is quite broad, we preset the material split in a series of monographic reviews on latttice techniques (downloadable in PDF format), *"The art of simulating the early Universe"*, *Part I* (Ref. [@Figueroa_2020rrl]), *Part II* (Ref. [@BaezaBallesteros_2025tme]), and *Part III* (Ref. [@Figueroa_2026XYZ]). These monographs, which are referred, colloquially, as $\mathtt{The~Art-I}$, $\mathtt{The~Art-II}$ and $\mathtt{The~Art-III}$ monographs, provide comprehensive discussions of lattice methods for scalar–gauge field theories in an expanding universe ($\mathtt{The~Art-I}$[@Figueroa_2020rrl]), gravitational waves and non-canonical aspects of field theory - including interactions, initial conditions, dimensionality - ($\mathtt{The~Art-II}$ [@BaezaBallesteros_2025tme]), and fluid dynamics as a description of an ensemble of interacting scalar, gauge, and fermion fields ($\mathtt{The~Art-III}$[@Figueroa_2026XYZ]).
